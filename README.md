# CampusHub

CampusHub is an Android app for keeping track of campus life, including classes, assignments, attendance, and academic resources.

## Open the project

1. Install [Android Studio](https://developer.android.com/studio).
2. In Android Studio, choose **Open** and select this project folder.
3. Let Gradle sync, then run the `app` configuration on an emulator or Android device.

The app uses Java, AndroidX, Material Components, and Gradle. Android SDK settings are managed locally by Android Studio and are not committed to this repository.
